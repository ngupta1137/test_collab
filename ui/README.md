# Verity UI

Front end for the Verity concept prototype: *One approved truth, in every channel.*

Pages: **Ask** (outcome cards for each channel and persona), **Author** (ingest a source, review queue with the publication gate, gaps, search insights, access, audit log), **Agents** (the same rules over MCP) and **Evals** (results by set and by domain).

The Verity engine runs server-side in `src/verity-engine/` (copied from the engine repo, tested there). All data is synthetic.

## Run it

```
bun install
bun run dev
bun run test
```
